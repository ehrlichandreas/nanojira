The exit code of each file is the verdict; the table is filled by hand from the

**Fixture root.** `H.freshDir()`/`H.mkBacklog()` create scratch fixtures
under `H.TMP_ROOT` — the realpath of `/tmp`, **not** `os.tmpdir()` — because
`os.tmpdir()` honours `TMPDIR`, and a `TMPDIR` whose own ancestor chain
happens to contain a real `backlog/` (another team's working tree, in an
environment this suite has actually run in) makes a "no backlog findable"
fixture silently find that unrelated backlog via nj's own upward search
(§ 4) instead of `no_backlog`. Set `NJ_TEST_ROOT=<path>` to use a different
root (trusted as given, no ancestor check performed); unset, `/tmp` is used.
